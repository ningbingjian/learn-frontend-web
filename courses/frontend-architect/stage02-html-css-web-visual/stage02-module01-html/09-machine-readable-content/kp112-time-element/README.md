## 学习目标

学完本节后，你应该能够：

1. 使用 `<time>` 同时提供人类可读文本和机器可读的 `datetime` 值。
2. 区分日期、时间、本地日期时间、带时区的全局日期时间和时长。
3. 理解页面展示文本可以本地化，而 `datetime` 应保持稳定、可解析。
4. 知道日期时间语义应优先使用 `<time>`，而不是通用 `<data>`。
5. 能通过 DOM API 观察 `textContent` 与 `dateTime` 的差异。

## 理论讲解

### 1. `<time>` 解决什么问题

页面常常要展示：

```text
2026 年 8 月 30 日
今晚 8:30
2 小时 30 分钟
```

这些文本适合人阅读，但程序更希望获得稳定格式：

```html
<time datetime="2026-08-30">2026 年 8 月 30 日</time>
```

浏览器展示的是元素内容，程序可以读取 `datetime`。

### 2. `datetime` 是机器值，不是视觉格式

例如同一个日期可以展示成：

```html
<time datetime="2026-08-30">2026/08/30</time>
```

也可以展示成：

```html
<time datetime="2026-08-30">8 月 30 日</time>
```

两者机器值仍然相同。

### 3. 常见日期时间形式

本节案例覆盖四类常见值：

```html
<time datetime="2026-08-30">2026 年 8 月 30 日</time>
<time datetime="2026-08-30T20:30:00+08:00">今晚 8:30</time>
<time datetime="20:30">20:30</time>
<time datetime="PT2H30M">2 小时 30 分钟</time>
```

其中 `PT2H30M` 是时长，而不是某个时间点。

### 4. 本地时间和带时区时间不要混淆

```text
2026-08-30T20:30
```

表达本地日期时间，本身没有说明时区。

```text
2026-08-30T20:30:00+08:00
```

则带有 UTC 偏移，可以更明确地表达时间点。

跨时区会议、日志时间、航班时间等场景尤其要明确这一点。

### 5. 日期时间不要用 `<data>` 代替

`<data>` 适合商品编号、枚举码等通用机器值；如果内容本质是日期或时间，应使用 `<time>`。

## 动手编码：从 0 到 1

### 第 0 步：创建最小 HTML

创建 `index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>KP112 time</title>
</head>
<body>
  <h1>time 元素实验</h1>
</body>
</html>
```

**本步目标**：准备可独立运行页面。  
**运行后观察**：浏览器可以正常打开页面。

### 第 1 步：加入日期

```html
<p>
  发布日期：
  <time id="publish-date" datetime="2026-08-30">2026 年 8 月 30 日</time>
</p>
```

**为什么这样写**：展示文本服务于读者，`datetime` 服务于程序。  
**观察结果**：页面显示中文日期，但 DOM 中保留 `2026-08-30`。

### 第 2 步：加入带时区的时间点

```html
<time id="meeting-time" datetime="2026-08-30T20:30:00+08:00">
  今晚 8:30
</time>
```

**为什么这样写**：跨系统交换具体时间点时，显式偏移能减少歧义。  
**观察结果**：显示“今晚 8:30”，机器值包含 `+08:00`。

### 第 3 步：加入纯时间和时长

```html
<time id="daily-time" datetime="20:30">20:30</time>
<time id="duration" datetime="PT2H30M">2 小时 30 分钟</time>
```

**为什么这样写**：一个是一天中的时间，一个是持续时长，它们语义不同。  
**观察结果**：两个元素都有 `datetime`，但格式并不一样。

### 第 4 步：用 JavaScript 观察两层值

```js
for (const item of document.querySelectorAll('time')) {
  console.log({
    text: item.textContent.trim(),
    datetime: item.dateTime,
  });
}
```

**为什么这样写**：直接验证“显示值”和“机器值”是两层数据。  
**观察结果**：控制台或页面实验区同时看到两种值。

### 第 5 步：对照最终源码

最终源码：[`index.html`](./index.html)。

- **本节核心代码**：`<time datetime="...">可读文本</time>`。
- **实验辅助代码**：JavaScript 只负责展示 `textContent` / `dateTime`，不是 `<time>` 语义本身。
