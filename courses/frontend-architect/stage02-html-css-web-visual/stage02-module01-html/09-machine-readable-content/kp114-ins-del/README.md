## 学习目标

1. 使用 `<ins>` 表示文档中新增的内容。
2. 使用 `<del>` 表示从文档中删除的内容。
3. 理解修订语义与普通删除线视觉效果的区别。
4. 使用 `datetime` 记录修改时间，使用 `cite` 指向解释修改原因的资源。
5. 能通过 DOM 检查修订类型、时间和来源。

## 理论讲解

### 1. `ins` / `del` 表达“文档修改”

例如会议安排从 19:00 改成 20:00：

```html
<p>
  开始时间：
  <del>19:00</del>
  <ins>20:00</ins>
</p>
```

这表达的不是单纯视觉样式，而是“旧内容被删除、新内容被加入”。

### 2. `datetime` 记录修改发生时间

```html
<ins datetime="2026-08-30T19:20:00+08:00">20:00</ins>
```

`datetime` 不是展示给用户看的修改说明，它是机器可读的修订时间。

### 3. `cite` 指向修改依据

```html
<del cite="./change-note.html">19:00</del>
```

`cite` 属性保存的是 URI，可以指向会议纪要、工单或变更说明。

如果用户需要看到原因，仍应在页面正文中提供可见说明；不要指望 `cite` 自动显示。

### 4. 修订语义和删除线样式不是一回事

CSS：

```css
.old { text-decoration: line-through; }
```

只能画线，不能表达“这段内容被从文档中删除”。

真正的文档修订应使用 `<del>` / `<ins>`。

### 5. `del` 不等于 `<s>`

- `<del>`：文档被编辑、内容被删除；
- `<s>`：内容仍在文档里，但已经不准确或不再适用。

下一节会专门比较这两个语义。

## 动手编码：从 0 到 1

### 第 0 步：准备最小页面

```html
<h1>版本说明</h1>
<p>会议安排已调整。</p>
```

### 第 1 步：标记旧内容被删除

```html
<del id="old-time">19:00</del>
```

**本步目标**：表达旧时间已经从当前版本中删除。  
**观察结果**：浏览器通常显示删除线，但核心是修订语义。

### 第 2 步：标记新内容被加入

```html
<ins id="new-time">20:00</ins>
```

**观察结果**：新旧内容同时展示，可以看出修改轨迹。

### 第 3 步：补充修改元数据

```html
<del
  datetime="2026-08-30T19:20:00+08:00"
  cite="./change-note.html"
>19:00</del>
```

`ins` 同样可以设置 `datetime` 和 `cite`。

### 第 4 步：加入可见修订说明

```html
<p>修改原因：发布会议延后 1 小时。</p>
```

**为什么这样写**：`cite` 属性本身不是给普通用户看的可见说明。

### 第 5 步：通过 DOM 观察属性

```js
for (const change of document.querySelectorAll('del, ins')) {
  console.log(change.tagName, change.dateTime, change.cite);
}
```

1. 页面能明确看出旧时间与新时间。
2. `del` / `ins` 都具有 `datetime`。
3. `cite` 指向一个修改说明 URI。
4. 页面正文中另有用户可见的修改原因。
5. JS 能区分 `DEL` 和 `INS`。
6. 能解释为什么 CSS 删除线不能替代 `<del>`。
