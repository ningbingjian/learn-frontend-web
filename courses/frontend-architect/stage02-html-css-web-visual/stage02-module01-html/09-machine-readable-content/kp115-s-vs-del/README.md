## 学习目标

1. 使用 `<s>` 表示已经不准确或不再适用的内容。
2. 使用 `<del>` 表示文档修订中的删除动作。
3. 能正确处理商品原价、售罄提示、规则变更等常见场景。
4. 理解“都有删除线”不代表语义相同。
5. 为删除线内容补充足够上下文，避免只依赖视觉效果传达含义。

## 理论讲解

### 1. `<s>`：内容仍存在，但已经不准确或不适用

典型商品价格：

```html
<p>原价：<s>¥299</s>，现价：¥199</p>
```

这里不是在展示“文档编辑历史”，只是说明 ¥299 已经不是当前有效价格。

### 2. `<del>`：明确表达文档删除修订

例如政策文档从：

```text
退款期为 7 天
```

改为：

```text
退款期为 14 天
```

可以写：

```html
<del>退款期为 7 天</del>
<ins>退款期为 14 天</ins>
```

这是文档变更历史，适合 `del/ins`。

### 3. 判断问题不是“想不想画删除线”

应该问：

```text
这段内容是被文档编辑删除了吗？
├─ 是 → del（通常可配 ins）
└─ 否，只是已经不准确/不适用 → s
```

### 4. 原价通常是 `s` 的经典场景

页面仍然主动保留原价用于比较：

```html
<s>¥299</s>
```

它没有从文档中被删除，所以一般不需要 `<del>`。

### 5. 不要只依赖删除线传递信息

辅助技术对删除线语义的朗读表现可能不同。

更稳妥的文案：

```html
<p>原价：<s>¥299</s>，现价：<strong>¥199</strong></p>
```

“原价”“现价”这些可见文本本身已经解释了变化。

## 动手编码：从 0 到 1

### 第 0 步：准备商品价格

```html
<p>商品价格：¥199</p>
```

### 第 1 步：增加不再有效的原价

```html
<p>原价：<s id="old-price">¥299</s>，现价：¥199</p>
```

**为什么使用 `s`**：¥299 仍然被页面保留用于价格对比，但它已经不是有效售价。

### 第 2 步：加入真正的文档修订

```html
<p>
  售后条款：
  <del id="old-rule">7 天无理由退货</del>
  <ins>14 天无理由退货</ins>
</p>
```

**为什么使用 `del`**：这里在展示条款从旧版本修改到新版本。

### 第 3 步：补充显式文本标签

```html
<span>原价：</span>
<s>¥299</s>
<span>现价：</span>
<strong>¥199</strong>
```

**本步目标**：即使忽略删除线样式，文本仍然可以理解。

### 第 4 步：用脚本验证元素类型

```js
console.log(document.querySelector('#old-price').tagName);
console.log(document.querySelector('#old-rule').tagName);
```

结果应分别是 `S` 和 `DEL`。

## 效果验证

1. 原价使用 `<s>`。
2. 售后旧规则使用 `<del>`，新规则使用 `<ins>`。
3. 页面不依赖删除线颜色或样式才能理解“原价/现价”。
4. JS 能显示 `S` 与 `DEL` 两种不同标签。
5. 能解释为什么原价一般不属于文档修订。
6. 能根据业务语义而不是视觉样式选择元素。
