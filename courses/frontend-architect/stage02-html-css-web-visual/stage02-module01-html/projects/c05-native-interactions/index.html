常见问题

如何修改密码？

进入账户安全设置，验证当前密码后即可设置新密码。

如何下载账单？

进入“账单与发票”，选择月份后下载 PDF 或 CSV。

如何导出工作区数据？

进入“数据管理 → 导出”，生成文件后系统会提供下载入口。
