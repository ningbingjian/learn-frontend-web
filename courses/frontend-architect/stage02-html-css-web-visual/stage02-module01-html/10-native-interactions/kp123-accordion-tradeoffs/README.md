## 学习目标

学完本节后，你应该能够：

1. 识别 `details/summary` 的原生交互优势。
2. 理解展开状态不会天然跨刷新保存，需要业务自行决定是否持久化。
3. 为 URL 片段深链接做渐进增强，而不是假设隐藏内容会自动展开。
4. 理解自定义动画会引入额外复杂度，并尊重 `prefers-reduced-motion`。
5. 认识折叠内容对搜索、发现性和关键任务信息的影响。

> **本节核心代码**：原生 `details` 的内容组织。  
> **实验辅助代码**：hash 深链接、状态保存和恢复。

## 理论讲解

### 1. 原生交互的主要优势

`details/summary` 已经提供：

- 状态语义；
- 键盘操作；
- 浏览器默认指示符；
- 不依赖 JavaScript 的基本可用性。

这让它非常适合从“可工作的 HTML”开始，再按业务需要增强。

### 2. 状态保存不是 HTML 自动提供的

用户打开一个 FAQ 后刷新页面，不能假设浏览器会替你恢复原状态。

如果恢复状态对产品有价值，可以使用：

- URL hash；
- `sessionStorage`；
- 路由状态；
- 服务端用户偏好。

不要为了纯装饰性的 FAQ 强行持久化所有状态。

### 3. 深链接需要明确策略

`#billing` 可以定位到一个元素，但不要依赖“跳转到折叠内容的内部节点就一定自动展开所有祖先 `details`”这种隐式假设。

更稳妥的增强方式是：

```js
const target = document.querySelector(location.hash);
const details = target?.closest('details');
if (details) details.open = true;
```

然后再滚动到目标。

### 4. 动画不是原生手风琴的核心价值

原生 `details` 的首要优势是语义和交互。如果为了高度动画把结构完全重写成大量 JS，可能得不偿失。

如果产品确实需要动画，应：

- 把它当增强层；
- 测试不同浏览器；
- 尊重 `prefers-reduced-motion`；
- 保证没有动画时仍然可用。

本节案例故意不依赖复杂动画。

### 5. 折叠会降低发现性

默认关闭意味着内容需要一次额外操作才能看到。不要把核心错误、总价、法律同意项或完成任务必须阅读的信息藏起来。

另外，浏览器查找页面文本、搜索引擎摘要和辅助技术对折叠内容的处理可能存在环境差异，不应把“可搜索到”当作唯一的信息架构策略。

## 动手编码：从 0 到 1

### 第 0 步：创建两个帮助主题

```html
<details id="billing-panel">
  <summary>账单说明</summary>
  <p id="billing">年付会一次性扣款。</p>
</details>
```

**本步目标**：建立可深链的真实内容节点。  
**为什么这样写**：URL 应指向有意义的内容。  
**运行后观察**：默认关闭。

### 第 1 步：为主题添加可复制链接

```html
<a href="#billing">直接打开账单说明</a>
```

**本步目标**：让状态能通过 URL 表达。  
**为什么这样写**：hash 可分享、可回退。  
**运行后观察**：URL 片段发生变化。

### 第 2 步：收到 hash 时打开祖先 details

```js
function revealHashTarget() {
  const target = document.querySelector(location.hash);
  const panel = target?.closest('details');
  if (panel) panel.open = true;
}
```

**本步目标**：实现可靠的深链接增强。  
**为什么这样写**：不依赖浏览器是否自动展开折叠祖先。  
**运行后观察**：点击链接后对应面板打开。

### 第 3 步：保存当前打开项

```js
sessionStorage.setItem('open-help', panel.open ? panel.id : '');
```

**本步目标**：演示状态持久化是额外业务逻辑。  
**为什么这样写**：明确区分 HTML 原生能力和产品增强。  
**运行后观察**：同一标签页刷新后可恢复打开项。

## 效果验证

1. 不运行 JavaScript 时，两个披露项仍可操作。
2. 点击“直接打开”链接会更新 hash 并展开目标面板。
3. 刷新同一标签页后可恢复最近打开的面板。
4. 清除 `sessionStorage` 后，恢复行为消失。
5. 能解释为什么状态保存和深链接属于增强逻辑，而不是 `details` 自动能力。
6. 能解释为什么重要信息不应该为了页面简洁而默认折叠。
