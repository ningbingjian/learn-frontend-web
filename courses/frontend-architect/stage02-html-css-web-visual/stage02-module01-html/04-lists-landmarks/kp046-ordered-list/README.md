## 学习目标

完成本节后，你应该能够：

1. 判断内容是否具有“顺序本身就是含义”的特征。
2. 使用 `<ol>` 与 `<li>` 编写操作步骤或排名。
3. 使用 `start` 指定起始编号。
4. 使用 `reversed` 生成倒序编号。
5. 使用 `li[value]` 在某一项改变编号，并理解后续编号会继续递增或递减。

## 理论讲解

### 1. 什么时候使用 `ol`

`<ol>` 是 **ordered list**，适用于顺序会影响内容理解的列表。

典型场景：

- 安装步骤；
- 操作流程；
- 比赛排名；
- 倒计时；
- 教程中的连续任务。

```html
<ol>
  <li>安装依赖</li>
  <li>启动开发服务器</li>
  <li>打开浏览器验证</li>
</ol>
```

如果把第 1 步与第 3 步随意调换，流程可能无法执行，因此使用 `<ol>` 比 `<ul>` 更合适。

### 2. `start` 从指定编号开始

`start` 用于指定列表第一项的编号：

```html
<ol start="4">
  <li>部署到测试环境</li>
  <li>执行回归测试</li>
</ol>
```

页面编号从 4 开始。

`start` 的值是整数，即使列表使用其他视觉编号样式，它表达的仍然是编号起点。

### 3. `reversed` 倒序编号

`reversed` 是布尔属性：

```html
<ol reversed>
  <li>第三名</li>
  <li>第二名</li>
  <li>第一名</li>
</ol>
```

列表会采用递减编号。

它特别适合：

- 倒计时；
- 从高到低的排行展示；
- 逆序步骤编号。

### 4. `li[value]` 改变当前编号

可以在某一个 `<li>` 上使用 `value`：

```html
<ol>
  <li>步骤 1</li>
  <li value="5">步骤 5</li>
  <li>步骤 6</li>
</ol>
```

第二项强制编号为 5，第三项会基于 5 继续编号。

因此 `value` 不是纯视觉样式，它会改变列表的编号序列。

不要为了“看起来像 5”而用 CSS 伪元素伪造核心步骤编号；当编号具有内容含义时，应优先让 HTML 本身表达。

## 动手编码：从 0 到 1

本节最终源码：[`index.html`](./index.html)

### 第 1 步：创建普通有序步骤

**目标**：表达一个有先后关系的发布流程。

```html
<ol id="release-steps">
  <li>构建产物</li>
  <li>上传测试环境</li>
  <li>执行验证</li>
</ol>
```

**为什么这样写**：发布流程中顺序会影响结果，所以使用 `<ol>`。

**运行后观察**：浏览器默认显示 1、2、3。

### 第 2 步：使用 `start`

**目标**：表达教程从第 4 步继续。

```html
<ol start="4" id="continued-steps">
  <li>创建发布标签</li>
  <li>推送生产环境</li>
</ol>
```

**为什么这样写**：列表并不是从完整流程的第 1 步开始，而是续接前文。

**运行后观察**：应显示 4、5。

### 第 3 步：加入倒序列表

**目标**：表达前三名倒序揭晓。

```html
<ol reversed id="ranking">
  <li>第三名：Team C</li>
  <li>第二名：Team B</li>
  <li>第一名：Team A</li>
</ol>
```

**为什么这样写**：编号需要递减，`reversed` 直接表达这种编号语义。

**运行后观察**：编号应从 3 倒到 1。

### 第 4 步：使用 `li[value]`

**目标**：演示某一项重设编号。

```html
<ol id="jump-number">
  <li>正常编号</li>
  <li value="5">从 5 开始</li>
  <li>继续编号</li>
</ol>
```

**运行后观察**：编号应为 1、5、6。

### 第 5 步：读取列表属性

**目标**：用辅助 JavaScript 验证 HTML 属性。

```js
const list = document.querySelector('#continued-steps');
console.log(list.start);
```

**为什么这样写**：用 DOM API 观察 `start` 属性的解析结果。

**运行后观察**：输出 `4`。

## 效果验证

你应该能够观察到：

- 默认有序列表编号为 1、2、3；
- `start="4"` 的列表从 4 开始；
- `reversed` 列表倒序编号；
- `li value="5"` 让编号跳到 5，后续继续为 6；
- HTML 中的编号语义不依赖 CSS。

控制台验证：

```js
document.querySelector('#continued-steps').start
```

预期：

```text
4
```
