## 学习目标

完成本节后，你应该能够：

1. 理解 `<dl>` 不是“任意两列布局”。
2. 使用 `<dt>` 表示名称、术语或键。
3. 使用 `<dd>` 表示对应描述、定义或值。
4. 表达一个名称对应多个描述。
5. 表达多个名称共享一个描述。
6. 判断术语表、商品元数据、配置说明等是否适合 `<dl>`。

## 理论讲解

### 1. `dl` 表达名称与描述关系

`<dl>` 是 description list。

它表达的是一组 **名称—描述** 关系，而不仅仅是视觉上的左右两列。

例如课程元数据：

```html
<dl>
  <dt>课程</dt>
  <dd>HTML 语义基础</dd>

  <dt>难度</dt>
  <dd>入门</dd>
</dl>
```

这里“课程”和“难度”是名称，“HTML 语义基础”和“入门”是对应值。

### 2. `dt` 与 `dd` 的职责

`<dt>`：description term，表示名称、术语、键。

`<dd>`：description details，表示描述、解释、值。

```html
<dl>
  <dt>API</dt>
  <dd>Application Programming Interface 的缩写。</dd>
</dl>
```

不要仅仅因为页面要做“两列布局”就选择 `<dl>`。

如果两列只是两个无关视觉块，应使用更符合内容语义的结构，再用 CSS 布局。

### 3. 一对多和多对一组合

一个 `<dt>` 可以对应多个 `<dd>`：

```html
<dl>
  <dt>HTML</dt>
  <dd>网页结构语言。</dd>
  <dd>由浏览器解析形成 DOM。</dd>
</dl>
```

这表示同一个名称拥有多条描述。

也可以多个 `<dt>` 对应一个 `<dd>`：

```html
<dl>
  <dt>JS</dt>
  <dt>JavaScript</dt>
  <dd>一种主要运行在浏览器中的编程语言。</dd>
</dl>
```

这适合别名、同义词等场景。

### 4. 适合术语表和元数据

常见适用场景：

- 术语与定义；
- 商品属性与值；
- 人物资料字段；
- 配置项与说明；
- FAQ 中非常明确的名称—描述关系。

不适合：

- 普通步骤：使用 `<ol>`；
- 同级项目集合：使用 `<ul>`；
- 长篇连续正文：使用段落、章节等结构；
- 纯粹为了左右对齐的布局。

## 动手编码：从 0 到 1

本节最终源码：[`index.html`](./index.html)

### 第 1 步：创建一个课程元数据列表

**目标**：使用 `dt/dd` 表达键值关系。

```html
<dl id="course-meta">
  <dt>课程名称</dt>
  <dd>HTML 语义基础</dd>

  <dt>学习阶段</dt>
  <dd>Stage 02</dd>
</dl>
```

**为什么这样写**：“课程名称 → HTML 语义基础”是一组名称与值的关系。

**运行后观察**：浏览器通常会为 `<dd>` 提供默认缩进，但默认样式不是核心。

### 第 2 步：加入一个名称对应多个描述

**目标**：观察 `<dt>` 后连续多个 `<dd>` 的关系。

```html
<dt>HTML</dt>
<dd>负责页面结构。</dd>
<dd>强调内容语义，而不是只负责视觉样式。</dd>
```

**为什么这样写**：两条说明都属于同一个术语 HTML。

### 第 3 步：加入多个名称共享描述

**目标**：表达简称和全称指向同一含义。

```html
<dt>JS</dt>
<dt>JavaScript</dt>
<dd>浏览器前端开发的核心编程语言之一。</dd>
```

**运行后观察**：DOM 中连续两个 `dt` 后跟一个 `dd`。

### 第 4 步：用 CSS 做展示，而不改变语义

```css
dl {
  display: grid;
  grid-template-columns: 10rem 1fr;
}
```

**为什么这样写**：HTML 负责关系，CSS 负责视觉布局。

**运行后观察**：名称和值变成双列展示，但去掉 CSS 后结构关系仍然存在。

### 第 5 步：统计 `dt` 与 `dd`

```js
const list = document.querySelector('#course-meta');
console.log(list.querySelectorAll('dt').length);
console.log(list.querySelectorAll('dd').length);
```

**为什么这样写**：辅助检查实际 DOM 元素数量。

## 效果验证

检查以下结果：

1. `#course-meta` 使用 `<dl>`。
2. 每个字段名称使用 `<dt>`。
3. 每个字段值或说明使用 `<dd>`。
4. 页面存在一个 `<dt>` 对多个 `<dd>` 的例子。
5. 页面存在多个 `<dt>` 对一个 `<dd>` 的例子。
6. CSS 只影响呈现，不改变描述关系。

控制台执行：

```js
document.querySelectorAll('#course-meta dt').length
```

和：

```js
document.querySelectorAll('#course-meta dd').length
```

观察实际名称和描述数量。
