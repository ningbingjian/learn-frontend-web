## 理论讲解

### 1. 文档根元素

完整 HTML 文档只有一个 `html` 根元素，`head` 和 `body` 位于它内部。JavaScript 可以通过 `document.documentElement` 直接取得该元素。

### 2. 文档主语言

`lang` 用于声明内容语言：

```html
<html lang="zh-CN">
```

它会帮助读屏发音、翻译工具、搜索引擎和断词算法理解文档。局部外语内容可以在自己的元素上覆盖 `lang`。

### 3. 书写方向与局部隔离

`dir` 表达整体书写方向，常用值包括 `ltr`、`rtl` 和 `auto`。方向未知的用户内容可以使用 `bdi` 隔离，避免订单号等文本影响周围的双向排版。

## 源码讲解

[`index.html`](./index.html) 的根元素声明 `lang="zh-CN"` 和 `dir="ltr"`。正文中的英文段落使用局部 `lang="en"`，订单号使用 `bdi`。

脚本通过 `document.documentElement` 读取根元素标签名、语言、方向属性和最终计算方向，使静态声明能够得到运行时验证。

## 运行案例

使用浏览器打开 [`index.html`](./index.html)，查看根元素属性输出。将根元素改成 `lang="ar" dir="rtl"` 后刷新，再观察页面方向和输出。

如需使用本地服务器，在当前目录执行 `python3 -m http.server 8080`，访问 `http://localhost:8080/index.html`。

## 效果验证

初始页面应显示：

- 标签名为 `HTML`。
- `lang` 为 `zh-CN`。
- `dir` 和计算方向均为 `ltr`。

改成阿拉伯语和 `rtl` 后，属性输出及页面整体方向应同步变化，局部英文语言声明仍保留在对应段落上。
