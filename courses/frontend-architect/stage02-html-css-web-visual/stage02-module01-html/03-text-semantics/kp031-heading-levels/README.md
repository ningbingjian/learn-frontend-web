## 学习目标

学完本节后，你应该能够：

1. 理解 `h1`～`h6` 表达的是标题层级，而不是字号大小。
2. 根据内容结构选择正确的标题级别。
3. 理解标题结构对键盘用户、读屏用户和文档导航的价值。
4. 能区分“语义层级”和“视觉样式”，不为了字体大小滥用标题标签。

> **本节核心代码是 `h1`～`h6` 的语义层级。**  
> JavaScript 只用于收集页面标题并输出层级列表，属于实验辅助代码。

## 理论讲解

### 1. 六级标题表示层级关系

HTML 提供六级标题：

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

数字越小，语义层级越高。

它们表达的是：

```text
页面主题
  └─ 一级分区
      └─ 二级分区
          └─ 更深层级
```

而不是：

```text
h1 = 最大字体
h6 = 最小字体
```

浏览器默认样式通常让 `h1` 更大，但这是 CSS 表现，不是标题语义本身。

### 2. 标题和字号是两件事

例如一个视觉上很小的组件标题，仍然可能是 `h2`：

```html
<h2 class="small-heading">系统通知</h2>
```

CSS 可以把它变小：

```css
.small-heading {
  font-size: 14px;
}
```

不要为了得到小字号而改成 `h5` 或 `h6`。

正确判断依据应该是：

> 它在当前内容结构中属于第几层？

### 3. 标题形成文档导航线索

标题能帮助用户快速扫描页面。

对辅助技术来说，标题还可以成为导航入口。读屏用户常常会按标题级别快速跳转，而不是从页面第一行逐字读取。

因此标题层级应该稳定反映内容关系。

### 4. 标题不是普通强调文本

下面这种写法不合适：

```html
<h3>库存不足</h3>
```

如果“库存不足”只是句子中的重点，而不是一个内容分区的标题，就应该使用普通文本配合合适的语义或样式，而不是为了加粗变大就使用标题标签。

## 动手编码：从 0 到 1 完成案例

### 第 0 步：创建最小页面

创建 `index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>KP031：h1～h6 标题层级</title>
</head>
<body>
</body>
</html>
```

### 第 1 步：写页面主标题

加入：

```html
<h1>前端性能手册</h1>
```

它表达整个页面的主题。

### 第 2 步：加入一级内容分区

继续加入：

```html
<h2>加载性能</h2>
<p>介绍资源加载阶段的性能问题。</p>

<h2>运行时性能</h2>
<p>介绍页面运行阶段的性能问题。</p>
```

现在两个 `h2` 都属于 `h1` 下的一级分区。

### 第 3 步：给加载性能增加子主题

在“加载性能”下面加入：

```html
<h3>关键资源</h3>
<p>识别首屏真正需要的资源。</p>

<h3>缓存策略</h3>
<p>减少重复网络传输。</p>
```

结构变成：

```text
h1 前端性能手册
├─ h2 加载性能
│  ├─ h3 关键资源
│  └─ h3 缓存策略
└─ h2 运行时性能
```

### 第 4 步：证明视觉大小不决定语义

加入：

```html
<style>
  h2 {
    font-size: 16px;
  }

  h3 {
    font-size: 24px;
  }
</style>
```

此时 `h3` 视觉上可能比 `h2` 更大，但它仍然是更低一级的标题。

这正好证明：

> 标题数字决定语义层级，CSS 决定视觉样式。

### 第 5 步：输出当前标题结构

为了方便观察，在页面底部加入：

```html
<pre id="result"></pre>
<script>
  const headings = document.querySelectorAll('h1, h2, h3, h4, h5, h6');
  document.querySelector('#result').textContent = Array.from(
    headings,
    heading => heading.tagName.toLowerCase() + ' -> ' + heading.textContent
  ).join('\n');
</script>
```

JavaScript 只用于实验观察。

### 第 6 步：完成案例并对照最终源码

最终代码应与仓库 [`index.html`](./index.html) 一致。

本节总结：

- **本节核心代码**：`h1`、`h2`、`h3` 等标题元素及其层级关系。
- **实验辅助代码**：CSS 的反向字号实验和 JavaScript 标题列表输出。

## 运行案例

直接打开 [`index.html`](./index.html)，或在当前目录执行：

```bash
python3 -m http.server 8080
```

访问：

```text
http://localhost:8080/index.html
```

## 效果验证

你应该能够确认：

- 页面只有一个主主题 `h1`。
- 两个 `h2` 与页面主主题形成父子关系。
- `h3` 是“加载性能”下的子主题。
- 即使 CSS 把 `h3` 设置得比 `h2` 更大，语义层级也不会改变。
- 能解释为什么不能为了字号大小选择标题标签。
