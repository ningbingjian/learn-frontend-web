## 学习目标

学完本节后，你应该能够：

1. 使用 `<p>` 表达一个文本段落，而不是把所有文字都放进 `<div>`。
2. 理解 `p` 的内容模型不适合包裹任意块级结构。
3. 观察浏览器遇到非法段落嵌套时的自动闭合行为。
4. 区分“段落语义”和“普通容器”两种用途。

> **本节核心代码是 `<p>` 的段落语义和内容边界。**  
> JavaScript 只用于输出浏览器最终生成的 DOM，属于实验辅助代码。

## 理论讲解

### 1. `p` 表达文本段落

典型写法：

```html
<p>HTML 使用语义元素描述内容角色。</p>
<p>CSS 负责页面视觉呈现。</p>
```

两个段落代表两个独立的文本思想单元。

### 2. `p` 不是通用布局容器

不要把 `p` 当作 `div` 使用：

```html
<p>
  <div>卡片内容</div>
</p>
```

这种结构不符合 `p` 的内容模型。

浏览器解析时会自动结束前面的 `p`，最终 DOM 往往和源码看起来不一样。

### 3. 段落会发生隐式结束

例如源码：

```html
<p id="demo">
  段落开始
  <div>块级内容</div>
  段落继续
</p>
```

浏览器不会简单保留“div 在 p 内部”的结构。

这和之前学过的 HTML 容错解析有关：

> 浏览器会根据 HTML 解析规则修正文档结构。

### 4. `p` 与 `div` 的区别

`p`：

- 表达自然语言段落。
- 自带明确文本语义。
- 内容模型有约束。

`div`：

- 通用无语义容器。
- 常用于布局、分组、脚本挂载。
- 不表示“这是一个段落”。

不要问“哪个更高级”，而要问：

> 当前内容是不是一个段落？

### 5. 段落间距应该交给 CSS

不要为了“空一行”连续写：

```html
<br><br><br>
```

段落结构应保持语义清晰：

```html
<p>第一段。</p>
<p>第二段。</p>
```

间距使用 CSS：

```css
p {
  margin-block: 1rem;
}
```

## 动手编码：从 0 到 1 完成案例

### 第 0 步：创建页面骨架

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>KP035：p 段落元素</title>
</head>
<body>
</body>
</html>
```

### 第 1 步：写两个正确段落

```html
<p>HTML 负责描述页面内容的结构与语义。</p>
<p>CSS 负责页面内容的视觉表现。</p>
```

### 第 2 步：加入普通容器作对照

```html
<div>这个 div 是普通容器，不自动表示文本段落。</div>
```

### 第 3 步：增加段落间距

```html
<style>
  p {
    margin-block: 1.5rem;
  }
</style>
```

这里用 CSS 管理视觉间距，而不是增加空 `p` 或多个 `br`。

### 第 4 步：增加一个非法嵌套实验

加入：

```html
<section id="experiment">
  <p id="broken-paragraph">
    段落开始
    <div id="inner-div">块级 div</div>
    段落后续文本
  </p>
</section>
```

这是故意写错的实验代码，用来观察浏览器自动修正。

### 第 5 步：输出最终 DOM

```html
<pre id="result"></pre>
<script>
  document.querySelector('#result').textContent =
    document.querySelector('#experiment').innerHTML.trim();
</script>
```

刷新后观察实际 DOM。

你会发现浏览器不会让 `div` 正常保留在那个 `p` 内部。

### 第 6 步：在 DevTools 中确认

打开 Elements 面板，分别查找：

```text
#broken-paragraph
#inner-div
```

对比源码和最终 DOM。

### 第 7 步：完成案例并对照最终源码

最终代码应与仓库 [`index.html`](./index.html) 一致。

- **本节核心代码**：正确段落、`div` 对照以及故意错误的 `p > div` 实验结构。

## 效果验证

你应该能够确认：

- 两个正常 `<p>` 分别表达独立段落。
- `div` 不表示段落语义。
- 段落视觉间距由 CSS 控制。
- 浏览器会修正 `p` 内部错误嵌套的块级结构。
- 能解释为什么 `p` 不能被当作通用容器使用。
