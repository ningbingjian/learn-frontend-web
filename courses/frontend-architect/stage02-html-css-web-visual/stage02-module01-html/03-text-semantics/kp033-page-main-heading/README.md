## 学习目标

学完本节后，你应该能够：

1. 使用 `h1` 表达页面当前内容的主主题。
2. 理解“通常一个清晰页面有一个主要 `h1`”和“HTML 并非语法上只能出现一个 `h1`”的区别。
3. 理解 `<title>` 与页面可见 `h1` 的职责差异。
4. 为详情页、文章页、后台页面设计清晰的主标题。

> **本节核心代码是页面可见的 `h1`。**  
> JavaScript 只用于对比 `<title>` 与 `h1`，属于实验辅助代码。

## 理论讲解

### 1. `h1` 表达当前页面的主主题

例如商品详情页：

```html
<h1>MacBook Pro 14 英寸</h1>
```

文章页：

```html
<h1>理解浏览器渲染流程</h1>
```

后台页面：

```html
<h1>订单管理</h1>
```

一个用户进入页面后，应该能通过主标题快速知道：

> 这个页面主要在讲什么？

### 2. `h1` 数量应该从信息结构出发

常见工程建议是：

> 对普通网页保持一个清晰的主要 `h1`，最容易维护和理解。

但不要把它误解成：

> HTML 语法强制每个文档只能出现一个 `h1`。

浏览器允许多个 `h1`。真正需要考虑的是多个顶级标题是否会让页面主题变得模糊。

### 3. `<title>` 和 `h1` 不是一回事

`<title>` 位于 `head`：

```html
<title>订单管理 - Admin Console</title>
```

主要用于：

- 浏览器标签页。
- 历史记录。
- 收藏夹。
- 搜索展示的重要信号。

`h1` 位于 `body`：

```html
<h1>订单管理</h1>
```

主要用于页面正文的可见主标题和内容结构。

二者应该相关，但不要求逐字完全一致。

### 4. 常见标题组织方式

一个常见模式：

```text
<title>具体页面名 - 产品名</title>
<h1>具体页面名</h1>
```

例如：

```html
<title>支付设置 - Cloud Console</title>
<h1>支付设置</h1>
```

这样既保留页面主题，也让浏览器标签页带有产品上下文。

## 动手编码：从 0 到 1 完成案例

### 第 0 步：创建页面骨架

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>支付设置 - Cloud Console</title>
</head>
<body>
</body>
</html>
```

### 第 1 步：写页面主标题

```html
<h1 id="main-heading">支付设置</h1>
```

用户进入页面后，可以立即识别当前任务范围。

### 第 2 步：增加二级分区

```html
<h2>默认支付方式</h2>
<p>管理账号默认使用的支付方式。</p>

<h2>账单联系人</h2>
<p>管理账单通知接收人。</p>
```

这里二级内容都属于“支付设置”这个主主题。

### 第 3 步：增加 `<title>` 与 `h1` 对照输出

```html
<pre id="result"></pre>
<script>
  const h1 = document.querySelector('#main-heading');
  document.querySelector('#result').textContent = [
    'document.title：' + document.title,
    'h1：' + h1.textContent,
    'h1 数量：' + document.querySelectorAll('h1').length
  ].join('\n');
</script>
```

### 第 4 步：观察两种标题职责

预期输出：

```text
document.title：支付设置 - Cloud Console
h1：支付设置
h1 数量：1
```

可以看到两者相关，但职责不同。

### 第 5 步：临时增加第二个 h1 做结构判断

临时在页面底部加入：

```html
<h1>帮助中心</h1>
```

思考：

- 浏览器可以正常解析吗？可以。
- 页面是不是立刻变成两个主主题？很可能是。
- 用户是否更难判断页面真正的主任务？是。

实验后删除第二个 `h1`。

### 第 6 步：完成案例并对照最终源码

最终代码应与仓库 [`index.html`](./index.html) 一致。

本节总结：

- **本节核心代码**：页面主 `h1` 与其下方 `h2` 分区。
- **实验辅助代码**：`document.title`、`querySelectorAll('h1')` 的对照输出。

## 效果验证

你应该能够确认：

- 页面主标题是“支付设置”。
- `<title>` 包含产品上下文“Cloud Console”。
- `h1` 和 `<title>` 内容相关但不完全相同。
- 当前最终案例只有一个 `h1`。
- 能解释“一个清晰主 `h1`”是信息架构建议，而不是浏览器语法限制。
