## 正式课程验收原则

每个 Lesson 至少做到：

1. 明确起始状态；
2. 精确到目录、文件和修改位置；
3. 每个 Step 只建立一个主要因果关系；
4. 明确运行方式和预期结果；
5. 给出完整最终源码；
6. 当前 Lesson 可以独立运行和验证；
7. 不把尚未学习的技术偷偷当作核心前置；
8. 解释“为什么”，而不只是给最终代码。
