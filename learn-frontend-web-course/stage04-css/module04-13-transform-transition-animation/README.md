# Module 04.13：Transform、Transition 与 Animation

## 模块目标

建立从静态变化到时间维度 UI 的完整 CSS 动画模型，并理解哪些动画容易产生 Layout/Paint 成本。

## Lesson 顺序

1. **04.13.01 Transform Coordinate 与 translate/scale/rotate/skew**。
2. **04.13.02 transform-origin 与 transform box**。
3. **04.13.03 2D/3D Transform 基础、perspective 与 preserve-3d 认知**。
4. **04.13.04 Transition：property / duration / timing / delay**。
5. **04.13.05 Easing 与 cubic-bezier / steps**。
6. **04.13.06 哪些状态适合 Transition**。
7. **04.13.07 `@keyframes` 与 Animation shorthand**。
8. **04.13.08 iteration / direction / fill-mode / play-state**。
9. **04.13.09 Multiple Animation 与组合边界**。
10. **04.13.10 Layout / Paint / Composite 成本的 Stage 04 心智模型**。
11. **04.13.11 transform/opacity 与 top/left/width 动画对比实验**。
12. **04.13.12 `will-change` 为什么不能乱加**。
13. **04.13.13 `prefers-reduced-motion` 与动画 A11Y**。
14. **04.13.14 Scroll-driven Animation 基础**。
15. **04.13.15 View Transition API 的 CSS 侧基础认知**。
16. **04.13.16 DevTools Performance / Rendering 动画验证**。
17. **04.13.17 综合实践：Drawer / Modal / Card / Loading 的可访问动画系统**。

## Definition of Done

能够独立设计 transition/keyframe 动画，尊重 reduced motion，并能通过 Performance 证据判断明显的 layout/paint/composite 成本差异。
