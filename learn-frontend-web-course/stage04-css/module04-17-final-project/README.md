# Module 04.17：Stage 04 CSS Architecture Review 与最终综合项目

## 模块目标

只使用 Stage 03 已学 HTML 能力与 Stage 04 CSS 能力，完成一个足够接近真实产品的响应式页面系统。项目不引入 React、Vue、Tailwind 或尚未学习的 JavaScript 应用能力。

## 推荐项目

**Responsive Product Console / Dashboard**

包含：

- 顶部导航与可折叠视觉布局；
- Sidebar / Main Content；
- Dashboard Grid；
- KPI Card；
- 表格与复杂表单视觉布局；
- Hero / Content Page；
- Light / Dark Theme；
- Responsive + Container Query；
- 可访问 focus / contrast / reduced motion；
- Token / Layer / Component Style Architecture。

## Lesson / Milestone 顺序

1. **04.17.01 需求、约束、Knowledge Ceiling 与验收标准**。
2. **04.17.02 信息架构与 HTML 基线复用**。
3. **04.17.03 CSS Architecture ADR：命名、Layer、Token、Theme**。
4. **04.17.04 Foundation：reset/base/type/token**。
5. **04.17.05 App Shell：Header / Sidebar / Main**。
6. **04.17.06 Dashboard Grid 与 Card System**。
7. **04.17.07 Table / Form / Status 视觉系统**。
8. **04.17.08 Responsive Viewport 设计**。
9. **04.17.09 Container-aware Component**。
10. **04.17.10 Dark / High Contrast / Reduced Motion**。
11. **04.17.11 Animation 与交互状态**。
12. **04.17.12 Failure Injection：溢出、长文本、极端数据、字体失败**。
13. **04.17.13 DevTools CSS Debug Report**。
14. **04.17.14 Performance Evidence：至少提交一份 Performance/Rendering 观察记录**。
15. **04.17.15 Compatibility Review 与 Progressive Enhancement**。
16. **04.17.16 Architecture Review：假设产品从 1 个页面增长到 100 个页面**。
17. **04.17.17 Final Delivery 与 Stage 04 答辩**。

## 最终交付物

- 完整 HTML + CSS 源码；
- README 与启动/查看方式；
- 多 viewport 截图或验证记录；
- Theme 与 Token 说明；
- CSS Architecture ADR；
- 至少一份 Failure Debug 报告；
- A11Y 检查记录；
- Performance / Rendering 证据；
- Compatibility / Progressive Enhancement 说明。

## Definition of Done

学习者不仅能“做出页面”，还必须能解释布局为什么稳定、样式为什么可扩展、出现故障如何定位，以及未来进入 React/Vue/Design System 后哪些 CSS 能力仍然保持有效。
