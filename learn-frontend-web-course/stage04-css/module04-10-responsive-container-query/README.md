# Module 04.10：Responsive Design、Media Query 与 Container Query

## 模块目标

从“几个固定断点”升级到内容驱动、组件驱动的响应式设计。

## Lesson 顺序

1. **04.10.01 Responsive Design 的问题域**。
2. **04.10.02 Mobile First 与 Content First**。
3. **04.10.03 Viewport 与 Stage 03 viewport meta 回顾**。
4. **04.10.04 Media Query：width / height / orientation / resolution**。
5. **04.10.05 用户偏好媒体特性**：dark、contrast、reduced-motion 等。
6. **04.10.06 Breakpoint 不应该绑定具体设备型号**。
7. **04.10.07 Fluid Layout：百分比、max-width、clamp 与弹性容器**。
8. **04.10.08 Responsive Image 与 CSS 布局协作**。
9. **04.10.09 Container Query 为什么存在**。
10. **04.10.10 `container-type` / `container-name` / `@container`**。
11. **04.10.11 Container Query Unit**。
12. **04.10.12 Style Query 认知与当前支持边界**。
13. **04.10.13 Logical Properties**：inline/block 与多语言布局。
14. **04.10.14 Safe Area 与 `env()`**。
15. **04.10.15 Failure Lab：桌面断点堆叠导致不可维护**。
16. **04.10.16 综合实践：同一 Card 在 Sidebar/Main/Full-width 三种容器自适应**。

## Definition of Done

能够基于内容和容器设计响应式规则，不依赖设备名单；能够同时处理 viewport、container、用户偏好和 logical direction。
