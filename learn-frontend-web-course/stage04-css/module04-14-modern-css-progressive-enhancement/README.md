# Module 04.14：Modern CSS 与 Progressive Enhancement

## 模块目标

系统收拢无法归入单一经典布局体系、但已经进入现代生产环境的重要 CSS 能力，并建立 Baseline / Feature Detection / Progressive Enhancement 思维。

## Lesson 顺序

1. **04.14.01 Modern CSS 不等于“新属性列表”**：能力、支持度与降级。
2. **04.14.02 `@supports` Feature Query**。
3. **04.14.03 Baseline 与浏览器兼容判断方法**。
4. **04.14.04 `:is()` / `:where()` / `:has()` 在真实组件中的组合复盘**。
5. **04.14.05 Nesting 原生 CSS**：语法、specificity 与迁移边界。
6. **04.14.06 Logical Properties 深入与 writing mode**。
7. **04.14.07 Intrinsic / Content-aware Layout 模式复盘**。
8. **04.14.08 Scroll Snap**。
9. **04.14.09 CSS Counter / Marker 进阶内容样式**。
10. **04.14.10 `accent-color`、form control styling 与平台边界**。
11. **04.14.11 `appearance`、`color-scheme` 与原生控件协作**。
12. **04.14.12 Popover / Anchor Positioning 的 CSS 协作边界与支持度核验要求**。
13. **04.14.13 Progressive Enhancement：核心功能先可用，再增强视觉能力**。
14. **04.14.14 Failure Lab：依赖单一新特性导致旧环境不可用**。
15. **04.14.15 综合实践：同时提供 modern path 与 graceful fallback 的组件页**。

## Definition of Done

学习者不会因为“新”就使用某项 CSS，而能基于 Baseline、目标用户、fallback 成本和业务收益做判断。
