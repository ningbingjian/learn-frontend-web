# Module 04.09：CSS Grid 完整体系

## 模块目标

掌握二维布局、显式/隐式网格、Track sizing、Auto Placement、Area、Subgrid，并能和 Flexbox 做正确选型。

## Lesson 顺序

1. **04.09.01 为什么需要 Grid：二维布局问题**。
2. **04.09.02 Grid Container / Item / Line / Track / Cell / Area**。
3. **04.09.03 `grid-template-columns/rows`**。
4. **04.09.04 `fr` 单位与剩余空间**。
5. **04.09.05 `repeat()` / `minmax()` / `fit-content()`**。
6. **04.09.06 Grid Line 定位与 span**。
7. **04.09.07 Named Line 与 Grid Area**。
8. **04.09.08 `grid-template-areas`**。
9. **04.09.09 Auto Placement Algorithm 高层模型**。
10. **04.09.10 Explicit vs Implicit Grid**。
11. **04.09.11 `grid-auto-flow` 与 dense 的边界**。
12. **04.09.12 Alignment 与 gap**。
13. **04.09.13 `auto-fill` / `auto-fit` 响应式卡片**。
14. **04.09.14 Subgrid**。
15. **04.09.15 Grid Item intrinsic size 与 overflow trap**。
16. **04.09.16 Flex vs Grid：从问题维度选型**。
17. **04.09.17 DevTools Grid Overlay**。
18. **04.09.18 综合实践：复杂 Dashboard + 数据卡片区域**。

## Definition of Done

能够设计二维页面骨架、响应式 track、auto placement 与 subgrid；能够解释 Grid 与 Flex 的职责差异，而不是凭偏好选型。
