# Module 04.11：Typography、Web Font 与 Text Layout

## 模块目标

掌握真实产品中的文字系统：字体栈、字体加载、行盒、换行、截断、可读性与国际化文本边界。

## Lesson 顺序

1. **04.11.01 `font-family` 与系统字体栈**。
2. **04.11.02 font-size / weight / style / stretch**。
3. **04.11.03 line-height 与 line box**。
4. **04.11.04 letter-spacing / word-spacing / text-align / decoration**。
5. **04.11.05 Web Font 与 `@font-face`**。
6. **04.11.06 字体格式、unicode-range、fallback**。
7. **04.11.07 FOIT / FOUT / font-display**。
8. **04.11.08 Font Metric 与 Layout Shift 高层认知**。
9. **04.11.09 Variable Font**。
10. **04.11.10 White Space、换行与 `overflow-wrap` / `word-break`**。
11. **04.11.11 单行/多行截断及其产品边界**。
12. **04.11.12 Hyphenation 与多语言文本**。
13. **04.11.13 Vertical Writing / Logical Text 基础认知**。
14. **04.11.14 A11Y：不要用极小字号、不要破坏缩放、对比度前置**。
15. **04.11.15 Failure Lab：Web Font 导致闪烁与布局跳动**。
16. **04.11.16 综合实践：产品 Typography Scale + Article/Card/Table 文本系统**。

## Definition of Done

能够设计稳定、可读、响应式的字体与文本体系，并能解释字体加载导致的 FOIT/FOUT 与布局变化。
