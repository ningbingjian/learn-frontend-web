# Module 04.12：Color、Background、Border、Image 与 Visual Styling

## 模块目标

系统掌握 CSS 视觉表达能力，同时建立颜色可访问性、图像成本和特效边界意识。

## Lesson 顺序

1. **04.12.01 CSS Color 基础：hex / rgb / hsl**。
2. **04.12.02 Alpha、透明与 compositing 高层认知**。
3. **04.12.03 Modern Color：lab/lch/oklab/oklch/color() 认知与使用边界**。
4. **04.12.04 `currentColor` 与颜色继承设计**。
5. **04.12.05 Background Color / Image / Position / Size / Repeat**。
6. **04.12.06 Multiple Background**。
7. **04.12.07 Linear / Radial / Conic Gradient**。
8. **04.12.08 Border / Radius / Outline**。
9. **04.12.09 Box Shadow / Text Shadow**。
10. **04.12.10 `object-fit` / `object-position` 与图片容器协作**。
11. **04.12.11 SVG Icon 与 `currentColor`**。
12. **04.12.12 Filter / Backdrop Filter**：效果、兼容与成本。
13. **04.12.13 Blend Mode / Mask / Clip-path 认知**。
14. **04.12.14 Dark Mode 与 High Contrast 的视觉边界**。
15. **04.12.15 Wrong Way：背景图承载关键内容、低对比度、过度滤镜**。
16. **04.12.16 综合实践：产品 Card / Hero / Status / Icon 视觉系统**。

## Definition of Done

能够选择合适颜色表示、背景/边框/图像方案，并在视觉效果、A11Y、性能和兼容之间做取舍。
