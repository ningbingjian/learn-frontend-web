Attribute Selector Laboratory

用 attribute 的存在、值、token、前后缀与大小写条件控制匹配集合。

实验 A：状态属性

Production / Active

data-state=active，data-env=PROD，data-tags 包含 urgent。

Staging / Idle

data-state=idle，data-tags 不含 urgent。

实验 B：字符串匹配边界

  • admin
  • administrator
  • not-admin

故意使用 substring selector 后，三个值都可能进入匹配集合。

实验 C：Hyphen 与 ASCII Case-insensitive

lang="zh-CN"

data-mode="DARK"
