CSS Error Recovery & Value Pipeline Laboratory

使用静态 HTML、CSS 与 DevTools，区分解析失败、无效声明和计算值阶段失败。

实验 A：同一规则中的无效声明不会破坏其他有效声明

本段的非法 color 被忽略，但背景和边框仍然存在。

浏览器不认识的 Property 被忽略，合法 color 继续生效。

实验 B：非法 Selector 与 Declaration Error 的作用范围不同

含非法 Selector 的整条规则不会匹配本段；后面的恢复规则仍可工作。

实验 C：Declared → Cascaded → Specified → Computed → Used → Actual

本段继承父元素颜色，并把百分比宽度解析为当前包含块中的使用值。

实验 D：Invalid at Computed-value Time

有效自定义属性可以参与 color。

自定义属性存在，但其 token 对 color 无效；观察 Computed 中最终颜色，而不要期待回退到前一条声明。

变量缺失时，显式 var() fallback 生效。
