拆开一条 CSS 规则

下面的组件分别用于观察选择器、声明块、多条声明、选择器列表和无效值恢复。

Ruleset

.anatomy-card { ... }

选择器决定匹配对象；花括号中的声明块决定要修改哪些 CSS 属性。

Attribute selector

[data-state="warning"]

同一个 HTML 结构可以因状态属性匹配到另一条规则。

Invalid value recovery

浏览器保留前一个有效颜色

CSS 中先声明有效的 color，再故意声明无效值；无效声明被忽略。

.anatomy-card
