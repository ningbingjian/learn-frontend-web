Specificity / Inheritance / CSS-wide Keywords Laboratory

只有当前面的 cascade 条件仍然打平时，Specificity 才开始比较；随后再观察继承与 CSS-wide keywords 怎样改变指定值。

实验 A：Specificity 比较，不是“选择器越长越强”

这个元素同时命中 type + class、class 和 ID 三条规则，ID 规则获胜。

这段使用 inline normal；在同为 Author normal 的前提下，它高于普通 selector rule。

实验 B：color 会继承，border 默认不会

子元素没有声明 color，也没有声明 border。它会继承父级文字颜色，但不会复制父级边框。

实验 C：inherit / initial / unset / revert

inherit：明确取父元素的 color。

initial：回到 color 的规范初始值，而不是“浏览器看起来默认的所有样式”。

unset：color 是继承属性，因此这里表现得像 inherit。

unset on border：border 非继承，unset 表现得像 initial，边框被清掉。

revert link：撤销 Author Origin 对 color 的修改，回退到 User / User-Agent 结果。
