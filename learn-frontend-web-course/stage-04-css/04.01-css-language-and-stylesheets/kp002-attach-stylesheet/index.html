CSS 怎样进入页面

三张卡片使用三种接入路径；第四张卡片用于观察相同优先级下的加载顺序。

Inline CSS

写在 style 属性中

style="border-color: #6d28d9"

Internal CSS

写在当前 HTML 的 style 元素中

<style> ... </style>

External CSS

由 link 元素请求独立 CSS 文件

<link rel="stylesheet" href="./styles.css">

加载顺序实验

外部样式表先把背景设置成蓝色；后出现的 Internal CSS 使用相同选择器将它覆盖成橙色。
